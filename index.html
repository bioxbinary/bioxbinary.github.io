Working Build · Hardware v1.2

DoseXTrack

● Working Prototype

A smart medication-monitoring system pairing an ESP32-driven dispenser with a real-time web dashboard over MQTT. Designed to grant independence to individuals managing strict schedules while giving caregivers verifiable peace of mind.

  • Real-time medication adherence tracking
  • Audible & visual multi-stage reminders
  • Physical tactile dispense confirmation button
  • Local-first telemetry over Mosquitto MQTT
  • C/C++ firmware built on ESP-IDF & FreeRTOS
  • Hardware timer & RTC clock sync via NTP
  • Non-blocking asynchronous event loop
  • Fail-safe local EEPROM dose queue storage
  • Lightweight pub/sub messaging via QoS 1
  • WebSocket bridge to web-based dashboard
  • Standardized JSON event payload schema
  • Sub-20ms round-trip latency on local Wi-Fi
  • ESP32-WROOM-32 microcontroller
  • Micro-servo mechanical gate actuator
  • 0.96" I2C OLED status screen & status LEDs
  • Custom 3D-printable PETG housing

Architecture

Where digital logic meets living care

An end-to-end local-first topology designed for absolute data autonomy, high fault tolerance, and zero external dependency.

LAYER 01

Edge Hardware

ESP32 dual-core microcontrollers running FreeRTOS. Low-power sensors, hardware interrupts, and mechanical actuation.

ESP-IDF · C/C++ · GPIO
LAYER 02

Local Message Bus

Deterministic MQTT broker routing high-frequency sensor readings and dispatch acknowledgments under 15ms.

Mosquitto · QoS 1 · WebSockets
LAYER 03

Edge Intelligence

Lightweight anomaly detection algorithms running on-device to flag missed cycles without leaking personal data.

Quantized ML · Zero Cloud
LAYER 04

Caregiver Dashboard

Clean, accessible web interface streaming live telemetry directly from local brokers. Offline-capable.

Vanilla JS · Reactive Streams
